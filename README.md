# Davines Serbia • Telegram Shop & WebApp

Элегантная система оформления заказов продукции **Davines** в Сербии для владельцев салонов красоты и мастеров-парикмахеров.

## 🌿 Особенности
- **Дизайн в фирменном стиле Davines**: минималистичная премиальная эстетика, чистая типографика, приглушенные натуральные тона.
- **Простая идентификация**: мастер указывает только **название своего салона** (остальные реквизиты хранятся у вас в офисной базе).
- **Мастер-каталог (296 позиций)**:
  - Новая линейка **Essential Haircare Evolution** (72 позиции во всех 9 семействах NOUNOU, MOMO, SOLU, DEDE, LOVE CURL, LOVE SMOOTH, MELU, VOLU, MINU с форматами 250ml, 1000ml, Refill 500ml, Refill 2L, твердыми шампунями и сыворотками).
  - Обновленная солнцезащитная линия **SU** (8 позиций с новинкой SPF 50).
  - Все основные линейки: *NaturalTech, OI, More Inside, Heart of Glass, Alchemic System, Boje & Finest Pigments, The Circle Chronicles, Pasta & Love, Travel Size и др.*
- **Удобная навигация**:
  - Горизонтальные вкладки линеек и подкатегорий.
  - Мгновенный живой поиск по названию или коду товара (например, `70031` или `nounou`).
  - Быстрое добавление и изменение количества (+ / -).
- **Цены в сербских динарах (RSD)**:
  - Отображаются актуальные розничные цены с НДС (**MP cena sa PDV**).
- **Двуязычный интерфейс**:
  - Мгновенное переключение между **Русским** (`🇷🇺 RU`) и **Сербской латиницей** (`🇷🇸 SR`).
- **Корзина и оформление**:
  - Подсчет общего количества позиций и итоговой суммы в RSD.
  - Формирование аккуратного структурированного списка с артикулами и суммами.
  - Мгновенная отправка заказа торговому представителю в Telegram.

## 🚀 Быстрый запуск и тестирование

### 1. Тестирование WebApp в браузере
Запустите локальный сервер:
```bash
python3 serve.py
```
Откройте в браузере: [http://localhost:8080](http://localhost:8080)
Вы сможете протестировать выбор товаров, смену языка, поиск и оформление заказа.

### 2. Подключение к Telegram
1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather):
   - Отправьте команду `/newbot` и задайте имя и username (например, `DavinesOrdersBot`).
   - Полученный токен вставьте в `config.py` в поле `BOT_TOKEN`.
2. Узнайте свой Telegram ID (например, через бота [@userinfobot](https://t.me/userinfobot)) и вставьте его в `config.py` в поле `MANAGER_CHAT_ID` (сюда будут приходить все оформленные заказы).
3. Опубликуйте папку `webapp` на любом бесплатном HTTPS-хостинге:
   - **GitHub Pages** (самый простой бесплатный вариант)
   - **Vercel** или **Cloudflare Pages**
   - Либо для локального теста используйте **ngrok**: `ngrok http 8080`
4. Вставьте ссылку на WebApp в `config.py` в поле `WEBAPP_URL` и настройте кнопку Menu Button в [@BotFather](https://t.me/BotFather) (`/setmenubutton`).
5. Запустите бота:
```bash
python3 bot.py
```
